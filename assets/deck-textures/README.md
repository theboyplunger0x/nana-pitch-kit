# Nana deck textures

These backgrounds carry the hybrid landing's visual system into the pitch deck: a smooth warm or lilac field and one oversized translucent lavender bubble cropped by the canvas edge. The current deck intentionally uses no grid motif.

## Files

- `nana-cream-bubble-top-right-nogrid.png`: full-resolution cream composition used by the current deck.
- `nana-cream-bubble-top-right-nogrid-deck.jpg`: lightweight 1280x720 deck version.
- `nana-lilac-bubble-bottom-left-nogrid.png`: full-resolution lilac composition used by the current deck.
- `nana-lilac-bubble-bottom-left-nogrid-deck.jpg`: lightweight 1280x720 deck version.
- `nana-purple-bubble-top-right-nogrid.png`: full-resolution manifesto composition used by the current deck.
- `nana-purple-bubble-top-right-nogrid-deck.jpg`: lightweight 1280x720 deck version.

The earlier grid-backed files remain in the folder only as historical source assets and should not be used in new slides.

## Generation note

Created with OpenAI's built-in ImageGen using this shared direction: minimal Nana Wallet 16:9 presentation background, warm cream/lilac or Nana-purple palette, smooth atmospheric gradient, one oversized translucent lavender glass bubble cropped by the canvas edge, ample negative space, no grid and no text.

Use only one atmospheric background per slide. Do not add small decorative bubbles on top; reserve the standalone asset in `../bubbles/` for diagrams where a bubble carries meaning.
