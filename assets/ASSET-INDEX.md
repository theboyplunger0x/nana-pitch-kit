# Asset index

## Current visual assets

- `logo/`: Nana avatars, wordmarks, banners and GitHub/social cards.
- `bubbles/`: the reusable translucent lavender glass bubble used throughout the current deck; this is the closest deck-ready asset to the landing's CSS bubble motif.
- `deck-textures/`: cream, lilac and purple 16:9 atmospheric backgrounds used by deck v3. Each has a full-resolution PNG and a lightweight deck-ready JPEG.
- `landing/`: the four product screenshots used by the hybrid landing and current deck.
- `nani/` and `sprites/`: Nani states for listening, thinking and completion.
- `screenshots-english/`: English product flow exports.
- `screenshots/`: Spanish product flow exports and secondary screens.
- `social/`: narrative frames and short clips created for the public launch/thread. Some retain earlier copy; use the narrative, not every line verbatim.
- `team/`: portraits currently used in the deck.
- `video-source/`: original scam-scenario footage.

## Reference-only assets

- `market/`: old market slides and PDF. These contain earlier segmentation work and should not be reused as sourced TAM slides without fresh research.
- `social/tweet12-endcard-1MB.png`: historical end card. Its line “Protection only you can provide” was superseded by “Protection when it matters.”
