# Nana glass bubble

`nana-glass-bubble.png` is the full-resolution reusable raster version of the landing-page bubble language. `nana-glass-bubble-deck.png` is the optimized copy embedded by the current deck.

Design intent:

- pale lilac translucent body;
- broad, diffused upper-left highlight;
- restrained purple inset shading along the lower-right edge;
- transparent background;
- no outline, icon, text or extra rings.

It can be scaled behind Nani, used as a small edge texture or carry a very short centered label. Preserve generous negative space and avoid turning it into a generic glossy 3D object.

Generation prompt summary: a restrained, almost-matte translucent lavender glass sphere on a true transparent background, with a soft white bloom at the upper-left and subtle deep-purple inset shading at the lower-right; one sphere only, no text, no icons, no iridescence, no cast-shadow puddle.
